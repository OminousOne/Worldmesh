An entity knows the other entities in its own group exactly: `me.local()` reads them directly. Entities in other groups it knows only by asking the spatial layer. Either way, it can read only their visible components.

## Asking

```rust
// Who's within 6 tiles of me, in any group?
me.query(6.0);
```

The question goes with the group's report to every Spatial Layer Cell whose area the circle touches. Move the asking entity, change the radius, or add cells, and see which cells get the question:

<ChunkMap mode="query" cells={3} />

Each cell answers before the group's next tick, so the answer is there on the next tick:

```rust
for s in me.sensed() {
    // s.id, s.x, s.y, s.group, s.player, s.kind(), s.get::<Health>()
}
```

An answer lists other groups' entities only, since your own group's are already exact. Answers are dropped after a second: ask again when you need fresher ones. The medieval example's bots ask every 200 ms, staggered by id so they don't all ask on the same tick.

## Using what you know

Two helpers combine both sources:

```rust
// My group's entities (exact) and others' (from the last answer), within 6 tiles.
let near = me.nearby(6.0);
// What I know of one entity, if anything.
let target = me.find(id);
```

Each `Nearby` says whether it's `local` (exact and current) or from an answer (a tick or two old).

## Keeping answers small

By default an answer lists everyone in the circle, with every visible component. In a crowd that adds up: fighting bots asking every 200 ms are most of the bus traffic. A `Query` narrows who and what:

```rust
// The 5 nearest, plus my foe if it's in range, and of each only whether it's dead.
me.query(Query::within(12.0).nearest(5).target(foe).with::<Dead>());
```

- **Ask only for the components you'll read.** The medieval bots only need to know who's dead. Asking for `Dead` alone cut the answers on the bus by 40% with 1,000 bots.
- **Ask about fewer entities.** `.nearest(n)` keeps the closest few; `.target(id)` always includes the one you care about.
- **Ask only when you need to.** A wandering bot that never fights never asks. A bot that was just hit doesn't need to either: the hit says who and where the attacker was (`Incoming::from`). In the medieval example, Combat keeps that in a `LastHit` component and Bots reads it.

Very large answers are split into several messages (at most 4,000 entities each), so none hits the bus's 1 MB message limit.
